LiQu Player

A powerhouse video player built with genuine Apple-style optical rim refraction, spherical fluid orbs, universal format support (YouTube, HLS, DASH, Direct), and intelligent low-RAM hardware adaptation.

Interactive Developer API Bench
Quick Start Integration

Drop into any website, webapp, Electron, Tauri, iOS WebKit, or Android WebView with zero build steps:

<!-- 1. Include CSS & JS --> <link rel="stylesheet" href="LiQuPlayer.css"> <script src="LiQuPlayer.js"></script> <!-- 2. Target Container --> <div id="player" style="max-width: 960px;"></div> <!-- 3. Initialize --> <script> const player = new LiQuPlayer('#player', { source: 'https://example.com/video.mp4', // MP4, HLS (.m3u8), DASH (.mpd), or YouTube URL title: 'The Odyssey - The Real Story', subtitle: 'S1 · E1', poster: 'assets/images/preview-odyssey-ship.png', glassMode: 'ultra', // 'ultra', 'balanced', or 'lite' ambientGlow: true }); </script>

True Optical Refraction

Uses SVG displacement filters and chromatic dispersion to realistically refract the video underneath at the rim with authentic rainbow prism fringe.

Universal Media Support

Plays direct HTML5 videos, HLS (.m3u8), MPEG-DASH (.mpd), YouTube URLs, and Vimeo with zero configuration under the same seamless liquid glass UI.

Old Device & Low RAM Mode

Built-in 3-tier hardware detection (Ultra Fluid, Balanced Frosted, Lite). Automatic map reuse and debounced canvas keep RAM under 15MB.

All Interfaces & Gestures

Responsive design for Web, Desktop (Electron/Tauri), Android app, iOS app, and PWA. Full double-tap to seek and vertical swipe brightness/volume.

MediaSession Integration

Syncs with system lock screen media notifications, hardware volume/seek keys, and external control centers on iOS, Android, macOS, and Windows.

Ambient Cinema Glow

Dynamic ambient lighting samples the video colors in real-time to cast a soft theater glow around the liquid player container.
